# traction.pretty — MANIFEST (datasheet-drawn footprints + standard-library picks)

Scope: the footprints KiCad's libraries do not provide, drawn from the manufacturer sheets archived in
`docs/datasheets/`, plus the standard-library pick for every other part the task listed, with the evidence.
Pad NUMBERS equal the schematic symbol's pin numbers (checked against `kicad/traction/traction.kicad_sym`,
`packages/cells.tsx`, `boards/*.tsx`). KiCad axes: +x right, +y down; units mm; ICs drawn pin 1 top-left.

Validation: each of the 18 drawn files was loaded and plotted with KiCad 10.0.6
`kicad-cli fp export svg --footprint <NAME> … kicad/traction/traction.pretty` (exit 0, no load error), and the
pad table of each was re-read and compared with the datasheet numbers below. Layers: pads, F.Fab body
(0.10), F.SilkS outline clipped ≥ 0.20 mm from copper (0.12), pin-1 mark on SilkS and Fab, F.CrtYd (0.05)
= body/pads + 0.25 (SMD) or + 0.50 (large THT), 0.01 grid.

Legend: **DEFECT** = the schematic/symbol must change; **PICK≠MAP** = the standard footprint the datasheet
supports differs from the one `calculations/footprints.mjs` currently maps (the parallel generator).

## C. Symbol / schematic pin-number findings (plain list)

1. **DEFECT — TPS55340QRTERQ1 (UB15), PowerPAD has no symbol pin.** TI Table 5-1 (TPS55340-Q1.pdf p.3): "The PowerPAD must be soldered to AGND." Every RTE footprint numbers it 17; the symbol stops at 16, so the EP lands with no net. Add pin 17 → DGND (the AGND pin 6 is on DGND here).
2. **DEFECT (footprint binding) — DMP6023LEQ-13 (QLVS) with `SOT-223-3_TabPin2`.** The symbol numbers the tab 4 (1 G, 2 D, 3 S, 4 TAB, both D and TAB on VBSW); TabPin2 has no pad 4. Either bind `SOT-223` (pad 4 = tab, matches the symbol as is) or drop symbol pin 4. The lead order itself matches the part.
3. **Not a defect, but geometry:** HCM75S12T4K3 numbers match (1 D, 2 S, 3 KS, 4 G), but the lead pitch is 5.08 / 2.54 / 2.54 (DS p.10 e1/e), not the uniform 2.54 of `TO247_4L()`.
4. **Recommendation — ALM2402QPWPRQ1 (UEXD), thermal pad 15 has no symbol pin.** TI p.3: "recommended to connect the Exposed Pad to ground … can be left floating." Floating is allowed; for the TVS/back-drive fault thermal budget, add pin 15 → AGND.
5. **Confirmed correct (datasheet = symbol numbers):** EconoDUAL3 1–11 (both HIITIO sheets); UCC14141-Q1 1–36; AMC1311 1–8; VOW3120 1–8; VGT12EEM 1–8 (6/7 NC); HC5FW 1–4 + E1–E4 as 5–8; ACT45B 1–4 (A = 1–4, B = 2–3); TE 770669-1 cavities 1–23; Samtec IPL1-120 row-by-row = `Header(40,2)`; NRVBAF360T3G 1 K; NCV4276C 1 IN / 2 INH / 3 GND+tab / 4 NC-VA / 5 OUT; BUK7Y14-80E; TCAN1042 (V); UCC28C40; 74LVC1G74; 74LVC3G17; FS2633D EP 49; all Nexperia 2-pin diodes pin 1 = K.
