# Vendor requests register (rev A.17)

Every WARN row in [`verification-report.md`](verification-report.md) and [`simulation-report.md`](simulation-report.md),
every open item in [`review-A15-disposition.md`](review-A15-disposition.md) "What stays open", and every
`parts-db.mjs` description containing "confirm", "RFQ", "quote", "Advance Information" or "planned" is a
question this design currently answers with an assumption instead of a datasheet fact. This register turns
each one into an exact, closeable question, one vendor per section. Companion document:
[`interface-requirements.md`](interface-requirements.md) — the same gates, from the OEM/vehicle side rather
than the component-vendor side; rows there are cross-linked from here as **IR-nn**.

> **Round-18 note.** The exciter network is now stable (rev A.17): amplifier node (DEXP/DEXN to VEXD) → RSX
> (anti-surge ESR18EZPF2R20) → protected node (SMDJ7.0A-HRA since round 19 — F203, the 8.5A left the parked-trickle case unclosable — monitor tap) → MF-MSMF020/33X → connector. **VR-17 is
> needed again** (its row carries the round-18 reason), **VR-33 (onsemi) is new** — the reverse rail current into
> ULDOEX — and VR-15/VR-16 keep their questions with the part numbers of the round-17 schematic.
>
> **Round-17 note.** The resolver-excitation protection network (RSX → TVS → PTC, amplifier to connector) is
> under active hardware change as of this register (see the repo's working-tree state; round 16 left it at
> F167–F170/gate ㉘, "What stays open"). **VR-15, VR-16 (Bourns) and VR-17 (Littelfuse, the SMCJ8.5A exciter
> TVS) describe the round-16 topology and part numbers** — re-check the part numbers and the design-condition
> column against the round-17 schematic before sending them. VR-19 (Littelfuse, the 1812L polyfuse) is unaffected.
> **VR-18 is withdrawn**: since the round-17 LV-entry change (F189, load-dump let-through) no TVS absorbs test B, so no
> long-pulse TVS rating is needed; the entry's open questions are VR-29 (NXP), VR-30 (TI), VR-31 (Panasonic), VR-32 (Bel).
